# RF Stock Statistical Analysis

I completed this Excel project for QNT 2020 at Baruch College, analyzing Regions Financial (RF) stock data.

## Workbook

Download `1-RF-Stock-Statistical-Analysis.xlsx` and open it in Excel. It contains my analysis and the price-history, quarterly income-statement, and dividend-history data sheets.

The analysis covers:
- Descriptive statistics and normality checks on daily stock returns
- Sampling distributions and confidence intervals
- One-sample hypothesis tests
- ANOVA on quarterly net margins
- Simple regression of closing price on earnings per share, with four RF charts
